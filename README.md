# Digital Uptime Astana — цифровая платформа мероприятия Devart × KazService

Практическое задание для Core-команды Devart
**Направление 3 — AI Content & Digital Product**

---

## Как запустить (30 секунд, без установки)

Откройте файл **`site/index.html`** двойным кликом в любом браузере.
Сборка, Node.js, интернет и установка зависимостей не нужны — это статические файлы.

> Если браузер откроет страницу без стилей, значит файл был распакован не целиком:
> распакуйте архив полностью, сохранив папку `site` со всеми файлами внутри.

### Необязательно: запуск через локальный сервер

Нужен только если хотите проверить страницу «как в проде» (с корректными путями и кешем):

```bash
cd site
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Что смотреть

| Шаг | Где | Что увидите |
|---|---|---|
| 1 | `site/index.html` | Сайт мероприятия: первый экран, программа, спикеры, FAQ, форма |
| 2 | Секция «Как это устроено» | Анимированная схема пути участника (медиаматериал) |
| 3 | Секция «Регистрация» | Заполните форму — увидите валидацию и экран успешной отправки |
| 4 | Ссылка внизу страницы → `site/crm.html` | Ваша заявка появится в CRM-доске в статусе «Заявка» |
| 5 | Кнопка «Продвинуть» на карточке | Участник двигается по статусам до Follow-up |

Кнопка **«Заполнить демо-данными»** в CRM добавляет 5 тестовых участников,
чтобы увидеть заполненную воронку целиком. **«Очистить всё»** — сброс.

Все данные тестовые и хранятся только в вашем браузере (`localStorage`).
Никуда не отправляются, сервера нет.

```
site/                     Главный результат — работающий прототип
  index.html              Сайт мероприятия
  crm.html                Внутреннее демо CRM-логики

  crm.js                  CRM-доска, статусы, тестовые данные

presentation/
  Devart_KazService_Digital_Product.pptx   Презентация, 5 слайдов
  build_deck.py                            Генератор презентации
  qa_deck.py                               Проверка вёрстки слайдов

docs/
  documents.html           Все три документа одним файлом — откройте в браузере
  01_sources_and_assumptions.md
  02_AI_Usage_Note.md
  03_limitations_and_next_steps.md
```

при необходимости сохраняется в PDF через «Печать → Сохранить как PDF».

## Проверено вручную

- Отправка формы: пустая форма, некорректный email, мусорный телефон,
  снятое согласие — отправка блокируется с понятной ошибкой у поля.
- Корректные данные: заявка сохраняется, показывается номер (`DU-0001`).
- Сквозной сценарий: заявка с сайта → карточка в CRM → перевод по статусам → сохраняется
  после перезагрузки.
- Мобильное разрешение 375 px: горизонтальной прокрутки нет, сетки в одну колонку.

Ограничения прототипа — в `docs/03_limitations_and_next_steps.md`.
